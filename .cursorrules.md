# Cursor Rules for PromptFlow

## Tech Stack & Architecture
- **Framework:** Flask (Python 3.10+), NOT Django. (The folder name `django-app` is legacy; do not import Django or assume Django patterns).
- **Database & ORM:** SQLite/PostgreSQL via Flask-SQLAlchemy, Alembic for migrations.
- **Forms & Auth:** Flask-WTF, Flask-Login, Werkzeug security (password hashing).
- **Testing & Quality:** Pytest, Ruff (linting & formatting).

## Strict Development Rules
1. **No Hallucinations on Tech:** Never suggest Django commands (`makemigrations` via Django, `django.db`, etc.). Use Flask equivalents (`flask db migrate`, SQLAlchemy models).
2. **Security First:** 
   - Always verify `login_required` on views.
   - Ensure object ownership checks (return 404 if the user doesn't own the project/scene/prompt).
   - Ensure CSRF tokens are present on all POST forms.
   - Validate and sanitize redirect URLs (prevent open redirects like `//evil.example`).
3. **Testing:** After modifying business logic or routes, ensure `pytest` passes. Do not break existing tests.
4. **Code Style:** Follow Ruff standards. Keep functions clean, modular, and well-typed where appropriate.
